# Macierz identyfikowalności SportRent

**Wersja:** 0.1

## 1. Cel macierzy

Macierz identyfikowalności przedstawia powiązania pomiędzy potrzebami klienta, wymaganiami systemowymi oraz historyjkami użytkownika (User Stories).

Jej celem jest zapewnienie, że każda potrzeba klienta znajduje odzwierciedlenie w wymaganiach systemu i planowanych funkcjonalnościach.

## 3. Historyjki użytkownika

**US-01 — Sprawdzanie dostępności sprzętu**

Jako klient chcę sprawdzić dostępność sprzętu, aby wiedzieć, czy mogę go wypożyczyć.

**US-02 — Przeglądanie informacji o sprzęcie**

Jako klient chcę zobaczyć szczegółowe informacje i cenę sprzętu, aby wybrać odpowiedni produkt.

**US-03 — Zarządzanie sprzętem**

Jako pracownik chcę dodawać, edytować i zmieniać status sprzętu, aby aktualizować jego dane.

**US-04 — Rejestrowanie wypożyczeń**

Jako pracownik chcę rejestrować wypożyczenia, aby kontrolować sprzęt przekazany klientom.

**US-05 — Rejestrowanie zwrotów**

Jako pracownik chcę rejestrować zwroty sprzętu, aby aktualizować jego dostępność.

**US-06 — Kontrola terminów zwrotów**

Jako pracownik chcę znać planowane terminy zwrotów, aby kontrolować aktualne wypożyczenia.

**US-07 — Rejestrowanie uszkodzeń**

Jako pracownik chcę zapisywać informacje o uszkodzeniach sprzętu, aby kontrolować jego stan techniczny.

**US-08 — Historia wypożyczeń**

Jako pracownik chcę przeglądać historię wypożyczeń, aby sprawdzać wcześniejsze operacje.

**US-09 — Łatwość korzystania z systemu**

Jako użytkownik chcę korzystać z prostego i czytelnego interfejsu, aby wykonywać zadania bez trudności.

**US-10 — Ochrona danych**

Jako użytkownik chcę, aby moje dane były odpowiednio chronione, aby korzystać z systemu w bezpieczny sposób.

## 4. Podsumowanie

Każda zidentyfikowana potrzeba klienta została powiązana z odpowiednimi wymaganiami systemowymi i historyjką użytkownika.

Macierz umożliwia kontrolowanie kompletności wymagań oraz śledzenie ich realizacji podczas dalszego rozwoju systemu.
