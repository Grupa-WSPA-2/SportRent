# ADR-001 — Wybór narzędzi do realizacji projektu

## 1. Kontekst

Podczas realizacji projektu SportRent potrzebowaliśmy narzędzi, które umożliwią wspólną pracę zespołu, zarządzanie zadaniami, przechowywanie dokumentacji oraz kontrolowanie zmian w projekcie.

## 2. Podjęta decyzja

Zdecydowaliśmy się wykorzystać następujące narzędzia:

| Narzędzie | Zastosowanie |
|---|---|
| GitHub | Przechowywanie kodu i dokumentacji, zarządzanie repozytorium. |
| GitHub Issues | Tworzenie i przydzielanie zadań członkom zespołu. |
| GitHub Projects | Organizacja pracy i śledzenie postępów. |
| Git | Kontrola wersji i zarządzanie zmianami. |
| Markdown | Tworzenie i formatowanie dokumentacji projektu. |

## 3. Uzasadnienie

Wybraliśmy te narzędzia, ponieważ ułatwiają nam wspólną pracę, pomagają dobrze zorganizować projekt, umożliwiają kontrolowanie zmian oraz zapewniają przejrzyste zarządzanie zadaniami i dokumentacją.

## 4. Konsekwencje decyzji

- Wszyscy członkowie zespołu mogą pracować na wspólnym repozytorium.
- Zadania są łatwiejsze do przydzielania i monitorowania.
- Historia zmian jest dostępna w Git.
- Dokumentacja jest przechowywana razem z projektem.
- Zespół może sprawdzać i zatwierdzać zmiany za pomocą Pull Requestów.

## 5. Status decyzji

Decyzja została zaakceptowana przez zespół i będzie stosowana podczas dalszej realizacji projektu SportRent.
