# Słownik SportRent — wersja 0.3

| Termin | Definicja |
|---|---|
| Sprzęt sportowy | Przedmioty sportowe dostępne w wypożyczalni. |
| Kategoria sprzętu | Grupa sprzętu o podobnym przeznaczeniu, np. rowery lub sprzęt narciarski. |
| Egzemplarz sprzętu | Konkretna sztuka sprzętu dostępna w wypożyczalni. |
| Numer identyfikacyjny | Unikalny numer przypisany do konkretnego egzemplarza sprzętu. |
| Dostępność sprzętu | Informacja, czy sprzęt można aktualnie wypożyczyć. |
| Stan techniczny | Informacja o sprawności i bezpieczeństwie użytkowania sprzętu. |
| Uszkodzenie sprzętu | Usterka lub zniszczenie, które może wpływać na użytkowanie sprzętu. |
| Wypożyczenie | Udostępnienie sprzętu klientowi na określony czas. |
| Zwrot sprzętu | Oddanie wypożyczonego sprzętu do wypożyczalni. |
| Termin zwrotu | Ustalona data, do której należy oddać sprzęt. |
| Rezerwacja | Zgłoszenie chęci wypożyczenia sprzętu w określonym terminie. |
| Klient | Osoba, która chce wypożyczyć sprzęt sportowy. |
| Pracownik | Osoba odpowiedzialna za obsługę wypożyczeń i zwrotów. |
| Kaucja | Kwota zabezpieczająca wypożyczalnię na wypadek uszkodzenia lub utraty sprzętu. |
| Cena wypożyczenia | Kwota, którą klient płaci za korzystanie ze sprzętu przez określony czas. |
| Okres wypożyczenia | Czas, na jaki sprzęt zostaje udostępniony klientowi. |
| Wyposażenie dodatkowe | Akcesoria przekazywane razem ze sprzętem, jeśli są wymagane. |
| Historia wypożyczeń | Zestawienie wcześniejszych wypożyczeń i zwrotów sprzętu. |
| Potrzeby klienta | Wymagania i oczekiwania klienta dotyczące wypożyczania sprzętu. |
| Zgłoszenie problemu | Informacja przekazana przez klienta lub pracownika o problemie ze sprzętem lub wypożyczeniem. |
