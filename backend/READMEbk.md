Folder przeznaczony na kod serwerowej części systemu SportRent do wypożyczania sprzętu sportowego.

Planowane technologie:
- Java
- Spring Boot

Planowane funkcje:
- Obsługa rejestracji i logowania użytkowników
- Zarządzanie sprzętem sportowym
- Obsługa wypożyczeń i zwrotów
- Sprawdzanie dostępności sprzętu
- Zapisywanie historii wypożyczeń
- Kontrola uprawnień użytkowników
