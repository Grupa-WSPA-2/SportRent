Folder przeznaczony na interfejs użytkownika systemu SportRent do wypożyczania sprzętu sportowego.

Planowane technologie:
- HTML
- CSS
- JavaScript

Planowane funkcje:
- Wyświetlanie dostępnego sprzętu sportowego
- Sprawdzanie dostępności sprzętu
- Rejestracja i logowanie użytkowników
- Wyświetlanie historii wypożyczeń
